# Tic-Tac-Toe

A two-player Tic-Tac-Toe game in plain HTML, CSS and JavaScript. Players take turns on one screen; the game spots a win or a draw and offers a restart.

**Portfolio:** [utkarash-thakur.vercel.app](https://utkarash-thakur.vercel.app)

## Features

- 3×3 grid; X and O take turns, and the status line shows whose turn it is.
- Checks all rows, columns and diagonals for a win after each move, and detects a draw.
- Game-over message with a Restart button.

## Tech stack

HTML · CSS · JavaScript (no libraries)

## Run locally

Open `index.html` in a browser.
